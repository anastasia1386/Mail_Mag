# MailSorter 信件歸檔工具

Outlook 信件自動分類歸檔工具，**免安裝、不需管理者權限**，適用已套用 GCB 的公務電腦。

只使用電腦既有的 **Windows PowerShell 5.1、Outlook、Word**：

- 以**下拉式選單**選擇 Outlook 資料夾作為資料來源（可多個，含共用信箱、封存資料檔，可含子資料夾）
- 依「寄件者／主旨／本文」規則，把信件存到對應的本機目錄，目錄不存在時可自動建立
- 信件本文轉成 **PDF**，也可保存原始 `.msg` 和附件
- **規則修改紀錄**：每次儲存規則都會記下時間、使用者、改了哪條規則的哪個欄位（修改前 → 修改後），可以篩選、匯出 CSV，也能還原到任一版本
- **預覽模式**：只列出每封信會存到哪裡，不會真的存檔
- **單一信件**：只處理 Outlook 中選取的信件或 `.msg` 檔，可依規則自動比對、指定套用某條規則，或手動選擇目錄；
  也可以用 `ArchiveSelected.bat` 不開管理介面，一鍵歸檔選取的信件

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `MailSorter.bat` | 雙擊啟動主程式 |
| `MailSorter.ps1` | 主程式（管理介面＋處理引擎） |
| `ArchiveSelected.bat` | 不開管理介面，直接依已儲存的規則歸檔 Outlook 中選取的信件 |
| `CheckEnv.bat` / `CheckEnv.ps1` | 環境檢查（建議第一次先執行） |
| `config.json` | 第一次執行後自動產生：資料來源、規則、選項 |
| `history\rules_*.json` | 規則修改紀錄，每次儲存新增一個檔案，不會覆寫 |
| `logs\處理紀錄_yyyyMMdd.csv` | 每次正式歸檔的處理結果 |

## 使用步驟

1. 把整個資料夾放在本機，例如 `D:\MailSorter`。
   如果是從網路下載的 zip，請先在 zip 檔「內容」勾選 **解除封鎖** 再解壓縮。
2. 雙擊 `CheckEnv.bat`，確認每一項都顯示「通過」。
3. 雙擊 `MailSorter.bat` 開啟管理介面。
4. **1. 資料來源**：從下拉選單選擇 Outlook 資料夾 → 按「加入為資料來源」。清單中打勾的才會處理。
5. **2. 規則**：新增規則，設定條件與存放路徑，按「儲存規則（寫入修改紀錄）」。可以在「修改說明」寫下修改原因。
6. **3. 選項**：設定檔名格式、處理天數、處理後要不要加 Outlook 類別等。
7. **4. 執行**：先按「預覽（不存檔）」確認結果，沒問題再按「開始歸檔」。
8. **5. 規則修改紀錄**：檢視、篩選、匯出 CSV，或還原到選取的版本。

## 規則說明

- 規則**由上而下**比對。勾選「符合此規則後，不再比對後面的規則」時，符合後就停止比對。
- **限定來源**：可以讓規則只套用在某個 Outlook 資料夾，例如只處理「共用信箱 > 收件匣」。
- 多個關鍵字用 `;` 分隔，任一個出現就算成立。「寄件者」會同時比對顯示名稱和電子郵件地址。
- 「條件組合」可選「全部條件成立 (AND)」或「任一條件成立 (OR)」。空白的條件不檢查。
- 勾選「使用規則運算式」後，關鍵字會以 Regex 比對，例如 `^\[公告\]`。
- 存放路徑與檔名可以用這些代碼：

| 代碼 | 內容 | 代碼 | 內容 |
|---|---|---|---|
| `{寄件者}` | 寄件者名稱 | `{yyyy}` | 收件年 |
| `{寄件者信箱}` | 寄件者 email | `{MM}` | 收件月 |
| `{寄件網域}` | email 的 @ 後面 | `{dd}` | 收件日 |
| `{主旨}` | 信件主旨 | `{HH}` / `{mm}` | 時 / 分 |
| `{規則}` | 規則名稱 | | |

  例如：`D:\公文信件\{寄件者}\{yyyy}{MM}` 搭配檔名 `{yyyy}{MM}{dd}_{HH}{mm}_{主旨}`，
  會存成 `D:\公文信件\王小明\202611\20261103_0930_會議通知.pdf`。

## 單一信件

**方法一：在管理介面處理**（「4. 執行」分頁的「單一信件」區）

1. 在 Outlook 選取一封或多封信件，或直接開啟某封信件的視窗。
2. 選擇「套用方式」：
   - **依規則自動比對**：和批次處理一樣比對規則。信件所在的 Outlook 資料夾如果是資料來源，「限定來源」的規則也會套用。
   - **手動選擇存放目錄…**：按下按鈕後選擇資料夾，信件的 PDF、MSG、附件會直接存到那個資料夾。
   - **套用規則：○○○**：直接使用該規則的存放路徑與輸出設定，不檢查條件（停用中的規則也可以指定）。
3. 按「處理 Outlook 選取的信件」。如果是已存在電腦裡的信件檔，改按「開啟 .msg 檔處理…」（可複選）。

- 勾選「只預覽」時不會存檔，並使用編輯中（含未儲存）的規則。
- 預設會略過已有「已歸檔」類別的信件；勾選「已歸檔過的信件也重新處理」可以強制再存一次。
- `.msg` 檔不在 Outlook 信箱中，處理後不會加類別或標示已讀。

**方法二：一鍵歸檔（不開管理介面）**

在 Outlook 選取信件後，雙擊 `ArchiveSelected.bat`。程式會依**已儲存**的規則自動比對並歸檔，完成後跳出結果視窗。
建議在桌面建立 `ArchiveSelected.bat` 的捷徑，或釘選到工作列，方便隨時使用。

> 進階用法：`MailSorter.ps1 -ProcessSelected -Preview` 只預覽；加上 `-Force` 時，已歸檔的信件也重新處理。

## 避免重複歸檔

預設會在歸檔完成的信件加上 Outlook 類別「已歸檔」，下次執行時略過有這個類別的信件（可在「3. 選項」調整）。
同名檔案會自動加上 `_2`、`_3`，不會覆蓋原有檔案。

## 規則修改紀錄

- 每次按「儲存規則」、「還原」，或關閉程式時選擇儲存，都會在 `history\` 新增一個 JSON 檔，內容包含：
  時間、Windows 帳號、電腦名稱、修改說明、逐項變更（新增／修改／刪除／順序），以及**該版本完整的規則內容**。
- 還原時會把選取版本的規則設為目前規則，**還原本身也會留下一筆紀錄**，所以紀錄只會增加、不會遺失。
- 「匯出全部紀錄 (CSV)」可以用 Excel 開啟，提供稽核或交接使用。
- 資料來源與選項的變更不列入規則修改紀錄。

## 無法執行時

| 狀況 | 原因與處理 |
|---|---|
| 雙擊 bat 沒有反應，或顯示「受限語言模式」 | GCB／AppLocker 將 PowerShell 設成 ConstrainedLanguage，請洽資訊單位將本程式加入允許清單 |
| 顯示「無法載入檔案…未經數位簽署」 | 檔案被標記為來自網際網路：在 `.ps1` 檔案「內容」勾選「解除封鎖」。如果是群組原則強制 AllSigned，請洽資訊單位簽章 |
| Outlook 跳出「有程式正在嘗試存取電子郵件地址」 | Outlook 的程式存取安全性設定，可選擇允許一段時間，或請資訊單位調整 |
| PDF 轉檔失敗 | 確認 Word 可以正常開啟；遇到加密或受 IRM 保護的信件時會記錄錯誤並略過 |

> 本程式不修改任何系統設定，也不繞過 GCB 管控。所有信件只在本機處理，不會傳到任何外部服務。
